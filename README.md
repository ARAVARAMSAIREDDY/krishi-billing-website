# Krishi Billing

Krishi Billing is an offline billing and shop management application designed for fertilizer shops.

## Features

- Fast and simple billing
- Product and price management
- Stock management
- Low-stock alerts
- Customer management
- Customer debt and payment ledger
- Professional invoice printing
- Sales history
- Sales and stock reports
- Backup and restore
- Works completely offline

## Technology

- Java
- JavaFX
- SQLite
- JDBC

## System Requirements

- Windows 10 or Windows 11
- 64-bit system
- No separate Java installation required when using the packaged installer

## Download

Download the latest Windows installer from the official Krishi Billing website.

## Privacy

Krishi Billing is designed to work offline. Shop data is stored locally on the user's computer.

## Version

Current version: 1.0.0

## Project

Krishi Billing is developed as a desktop application for fertilizer shop owners and shop staff.
